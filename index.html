JARVIS – Política de Privacidade

Atualizada em 28 de outubro de 2026

O JARVIS é um assistente pessoal de uso privado, criado e usado exclusivamente por Ryan Nishioka. Não é oferecido ao público.

Dados acessados

Com autorização do próprio Ryan, o JARVIS acessa a conta Google dele (Gmail, Google Agenda e Google Drive) para ler, organizar e, somente após confirmação manual, enviar emails e criar ou alterar eventos.

Como os dados são usados

Os dados são usados apenas para responder aos pedidos do Ryan. Para isso, o conteúdo necessário é enviado para processamento à API do Claude (Anthropic) e, no caso de áudios, à API de transcrição da Groq. Nenhum dado é vendido, compartilhado com terceiros para outros fins ou usado para publicidade.

Armazenamento

O histórico de conversa e as anotações ficam num banco de dados no computador ou servidor do próprio Ryan. Os tokens de acesso ficam no mesmo lugar e não são compartilhados.

Revogar acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
